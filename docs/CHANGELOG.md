# OneBar 1.1.0-local.2 更新事实

相对旧版本的累计改动：

- 递归显示子文件夹，提示词胶囊通过独立浮动窗口展开，不受主导航背板高度限制；父子层级紧贴排列，无连接线。
- 主导航默认白色，选中深灰色；弹出按钮未选中白色，选中后使用所属分支色系。预设五级色调，逐级提亮；更深层沿用最后一级，五级是色阶数量而非文件夹层数上限。白色、灰色不作为分支色系。
- 更换透明背景图标，应用、桌面入口、任务栏、托盘及安装入口使用更新的图标资源。
- 默认回收等待和动画由各 500ms 改为各 333ms，约为原耗时的三分之二；按最深子级到父级回收，主导航最后回收。多个层级共享动画预算，不按层累加完整动画时长。
- 保留设置、托盘、开机启动、单实例、关闭键行为及本地文件工作流。鼠标返回可取消回收，锁定可阻止自动回收。

升级保留已有设置，333ms 默认值不强制覆盖旧值。运行依赖 Windows x64；已在当前本机验证，不构成所有 Windows 版本与第三方软件兼容性承诺。安装包未签名。
