# 验证范围

产品既有本机证据：当前版本 1.1.0-local.2 已安装到本机；安装后应用文件与构建输出校验值一致。用户工作流 39 个文件的文件集和哈希未变化，除回收两项时间改为 333ms 外，其余设置保留。

针对回收逻辑：通过真实 WPF 窗口和 Dispatcher 的隔离计时测试，验证无分支、两级与五级时最深层先隐藏，导航最后回收；验证中途取消恢复和锁定阻止回收。窗口不依赖物理鼠标操作，结果见 `evidence/retraction-timing.json`。三个总耗时为 702ms、645ms、692ms，有调度误差，不承诺每次精确 666ms。安装后设置窗口核验两项均为 333ms。

复制与拖放曾在上一候选版做针对性验证，本次回收改动未重复覆盖所有接收应用。以上是单机记录，非自动 CI 或全平台认证。

包制作时另外核对源码与当前构建源文件一致、冻结安装包哈希、图标资源一致，排除 bin/obj、用户设置、个人工作流和历史记录，并逐项复核 ZIP 内容校验值。源码交付构建检查结果见 `evidence/source-build.json`。

未完成：干净机器首次安装和卸载、全部历史版本升级、多屏/不同 DPI、所有 Windows 10/11 版本、各聊天软件拖放、远端下载与公开发布验收。没有新版公开截图，不把历史测试版截图当作本版画面。

冻结安装包与本机已安装版本使用同一原始构建，原安装包包含 OneBar.pdb 调试符号，可能包含构建源路径；没有提取加入散装调试文件。若管理员移除符号后重新打包，安装包校验值将变化，须重新进行安装验收并更新清单。源码构建脚本已默认排除新安装包中的散装 PDB。
