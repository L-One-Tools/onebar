# 安装与升级

安装文件：`release/OneBar_Setup_v1.1.0-local.2.exe`，Windows x64，自包含 .NET 运行时；最终用户无需安装开发 SDK。

升级前备份当前工作流目录及 `%APPDATA%\OneBar\settings.json`，从托盘退出旧程序，再运行安装程序并确认原安装目录。不要直接删除旧目录或个人工作流。本安装包沿用原应用标识，已有设置存在时不重新写入首次安装配置。

需要更快回收时，打开 OneBar 设置，在“自动回收”中把“离开后停留（ms）”及“回收动画（ms）”都改为 333 后保存。新安装默认为这两个值；升级用户的原设置保留。

首次使用：在设置中确认工作流目录，将 .md 或 .txt 文件放入分类及其子文件夹。打开分类可继续展开，点击文件复制文本，也可拖动文件到支持接收文件的应用。拖放是否可用取决于接收应用，不能保证所有输入框支持。

设置位于当前用户的 `%APPDATA%\OneBar\settings.json`，工作流以设置中选择的目录为准；不要因本机曾使用 D 盘目录而硬编码给其他用户。卸载或回退前另行备份，两者的数据保留行为应由管理员在隔离用户中实测。

当前安装包未数字签名。若系统提示来源不明，应先核对发布渠道和校验值，不应直接关闭系统安全防护。
